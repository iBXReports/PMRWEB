Desglose Técnico y Funcional de CODIGOAGENTE.html

🚀 Propósito General

CODIGOAGENTE.html es una aplicación web de una sola página (SPA) diseñada como un Dashboard Táctico Móvil para los agentes de PMR (Personas con Movilidad Reducida) en entornos aeroportuarios. Su objetivo es centralizar la recepción de tareas, el seguimiento de pasajeros en tiempo real y la gestión administrativa del personal en una interfaz optimizada para teléfonos y tablets.

HTML5 CSS3 (Variables & Glassmorphism) JavaScript (Vanilla) Supabase JS SDK Firebase SDK OpenWeather API

🛠️ Arquitectura de Datos

El sistema utiliza un enfoque híbrido de base de datos para garantizar resiliencia y velocidad:

  • Supabase (Primaria): Se encarga de la gestión de la tabla pasajeros_pmr. Utiliza Canales (Channels) para actualizaciones en tiempo real via WebSockets.
  • Firebase (Sincronización): Funciona como un nodo de respaldo y motor de notificaciones rápidas a través de Firestore, escuchando cambios mediante onSnapshot.
  • API Backend: Se comunica con un servidor central mediante la función fetchJson para operaciones que requieren lógica de servidor (como el logueo masivo o auditorías).

📱 Módulos Funcionales

1. Sistema de Autenticación

Permite el acceso mediante el RUT del agente. El sistema normaliza el RUT automáticamente y persiste la sesión localmente (localStorage) para permitir el autologin rápido.

2. Gestión de Tareas (Dashboard)

Presenta las asignaciones enviadas por el supervisor. Los agentes pueden:

  • Ver detalles del vuelo, pasajero y tipo de asistencia (SSR).
  • Aceptar / Iniciar / Finalizar tramos con un solo toque.
  • Recibir alertas sonoras (noti1.mp3) y visuales ante nuevas tareas.

3. Seguimiento de Tramos (Pestaña Tramos)

Es el corazón operativo. Muestra una tabla detallada de todos los movimientos en el aeropuerto. Incluye selectores rápidos para:

  • Tomado En / Dejado En: Ubicaciones predefinidas (Puente, Plaza, Counters, etc.).
  • Status Pax: Estado actual del pasajero (Contactado, Embarcado, etc.).
  • Filtros Avanzados: Por aerolínea (logos interactivos), número de vuelo o nombre del pasajero.

4. Calendario y Turnos

Un potente módulo de Gestión de Roles Mensuales. Permite visualizar el calendario del mes con colores distintivos por turno (M, T, N, Libre, Vacaciones, etc.). Incluye una "paleta de pintura" para que el supervisor o el sistema asignen turnos de forma visual.

5. Gamificación (RPG System)

Convierte la operación técnica en una experiencia de progresión:

  • Niveles y XP: Basado en tareas completadas con éxito.
  • Rango: Estados como "Especialista T1" para incentivar la calidad.
  • Medallas: Logros visuales por desempeño.

🎨 Diseño y UX

  • Temas Dinámicos: Soporte total para Modo Oscuro (oscuro profundo para la losa del aeropuerto de noche) y Modo Claro.
  • Touch-First: Todos los botones y selectores tienen un área de contacto mínima de 40px para evitar errores táctiles.
  • Widgets en Vivo: Incluye un reloj digital de alta precisión, estado de la base de datos (DB Online/Offline) y un widget de clima real para SCL/Pudahuel.
  • Micro-animaciones: Uso de cubic-bezier para transiciones suaves y barras de carga animadas.

🔍 Lógica de Programación Clave

Optimismo en la UI: El script aplica "Actualización Optimista". Cuando un agente cambia un estado, la interfaz se actualiza inmediatamente en el cacheTramosAgente local antes de esperar la respuesta del servidor, haciendo que la App se sienta instantánea.

Funciones críticas documentadas en el código:

  • actualizarDatoTramoAgente(): Orquestador que guarda en Supabase, Firebase y notifica al resto de la red simultáneamente.
  • renderTramosAgente(): Motor de búsqueda y paginación que filtra miles de registros en pocos milisegundos.
  • initShiftLogic(): Maneja la matriz de turnos mensuales y la persistencia de colores.
